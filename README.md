Gadget Store – E-Commerce Website

Created by: Vedish Patel
Role: Computer Science Student

Gadget Store is a full-stack e-commerce web application designed for browsing and purchasing electronic gadgets and accessories. Users can explore products, search for items, view product details, add products to their shopping cart, and place orders.

The application includes an admin dashboard for managing products, updating prices and stock, and viewing customer orders.

Tech Stack: HTML, CSS, JavaScript, Node.js, Express.js, and MySQL.

Key Features:

Product listing and search

Shopping cart management

Checkout and order placement

Product and inventory management

Admin dashboard

Responsive user interface

Objective: To develop a simple, user-friendly online shopping platform that demonstrates full-stack web development, database management, and basic e-commerce functionality.
